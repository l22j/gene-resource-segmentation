# 🌱 AI 기반 이미지 세분화 시스템

이미지에 **작물 점**과 **배경 점**을 찍으면 SAM(Segment Anything)이 작물 영역을 분할하고, 결과 마스크를 저장하는 라벨링 도구입니다.

- 모델 3종(ViT-B / ViT-L / ViT-H) 중 골라서 사용
- 점을 찍거나 옮길 때마다 결과를 옆 화면에 바로 표시
- 점 이동 · 삭제 · 작물/배경 전환, 되돌리기(Ctrl+Z)
- 한 이미지에 여러 포기(객체)를 따로 라벨링
- 저장한 이미지는 다시 열면 점이 복원되어 이어서 수정 가능

> 📘 같은 내용을 보기 좋게 정리한 **[사용설명서.html](사용설명서.html)** 도 있습니다. (더블클릭해서 열기)

---

## 0. 어떤 버전을 쓰면 되나요?

같은 기능을 두 가지 방식으로 제공합니다. **처음이라면 브라우저 버전(v2)을 쓰세요.**

| | **브라우저 버전 (권장)** | 파이썬 서버 버전 |
|---|---|---|
| 실행 | `AI_이미지_세분화_시스템_v2.html` 더블클릭 | `run_sam_label.bat` 더블클릭 |
| 설치 | 없음 (Chrome / Edge 만 있으면 됨) | 파이썬 + PyTorch + segment_anything |
| 모델 | 브라우저용으로 변환된 SAM (처음 한 번 자동 다운로드) | 폴더 안의 `.pth` 가중치 |
| 인터넷 | 필요 (실행할 때 AI 엔진을 받음) | 필요 없음 |
| ViT-H | 매우 느림 (이미지 한 장 1~2분) | 정상 속도 |
| 배포 | HTML 파일 하나만 보내면 됨 | 폴더 전체 + 파이썬 환경 |

저장되는 결과 파일의 형식은 두 버전이 같아서, 한쪽에서 만든 라벨을 다른 쪽에서 이어서 수정할 수 있습니다.

## 2. 브라우저 버전 시작하기

### 필요 환경
| 항목 | 내용 |
|---|---|
| 브라우저 | **Chrome 또는 Edge 최신 버전** (폴더 열기 · 저장 기능 지원) |
| 그래픽카드 | WebGPU 를 지원하는 그래픽카드 권장 (최근 NVIDIA / AMD / Intel). 없으면 CPU 로 동작하지만 느림 |
| 인터넷 | 실행할 때마다 AI 엔진(라이브러리)을 받고, 모델은 처음 한 번만 받음 |
| 저장공간 | 모델이 브라우저에 저장됨 (ViT-B 약 0.2GB, ViT-L 약 0.6GB) |

### 처음 실행
1. `AI_이미지_세분화_시스템_v2.html` 을 **더블클릭**합니다. (기본 브라우저가 Chrome/Edge 가 아니면 파일을 Chrome 으로 끌어다 놓으세요)
2. "모델 불러오는 중" 창이 뜨고 모델을 다운로드합니다. 처음에만 시간이 걸리고, 다음부터는 브라우저에 저장된 파일을 씁니다.
3. 위쪽 **↺ 새 작업** → **이미지 폴더 선택**으로 폴더를 고르고, 브라우저가 묻는 **"파일 보기"** 권한을 허용합니다. (저장 폴더도 여기서 미리 고를 수 있습니다)
4. 점을 찍고 **Ctrl+S** 로 저장합니다. 처음 저장할 때 **저장 폴더**를 고르고 **"변경 사항 저장"** 권한을 허용합니다.

### 다음 실행
왼쪽에 **지난 작업** 상자가 나타나면 **이어서 열기**를 누르세요. 지난번 이미지 폴더와 저장 폴더가 그대로 열립니다.
(브라우저 보안상 폴더 권한을 다시 확인하기 때문에 클릭 한 번이 필요합니다)

### 모델 고르기 (화면 위쪽)
| 모델 | 다운로드 | 이미지 분석 | 추천 |
|---|---|---|---|
| ViT-B (빠름) | 약 181MB | 약 1~3초 | 빠르게 많이 라벨링할 때 |
| **ViT-L (중간)** | 약 620MB | 약 3초 | **정확도가 중요할 때 (권장)** |
| ViT-H (매우 느림) | 약 661MB | 약 1~2분 | 브라우저에서는 비권장 → 파이썬 버전 사용 |

- 이미지를 처음 열 때만 분석 시간이 걸리고, **점을 찍을 때는 0.1초 안팎**으로 바로 반응합니다.
- **정밀도**는 "자동"을 권장합니다. (그래픽카드에 맞춰 fp16 / fp32 / 8bit 중 선택)
- 속도는 RTX 3080 Ti 기준으로 잰 값입니다.

각 기능은 **한 곳에만** 있습니다.

| 위치 | 내용 |
|---|---|
| 왼쪽 레일 | 보기 전환 **라벨링**(원본+결과) · **원본** · **결과**(한쪽만 크게), **설정**, **도움말**(조작법·단축키) |
| 위쪽 왼쪽 | **↺ 새 작업**: 이미지 폴더 · 저장 폴더 고르기 (처음 시작할 때도 여기서) |
| 위쪽 오른쪽 | 이전/다음 이미지, 자동저장, 모델, 정밀도, 화면 맞춤(⛶), 되돌리기, 저장 |
| 지표 카드 | **진행률**(완료/전체, 남은 장수) · **현재 이미지**(이름, 크기, 저장 상태) · **AI 상태**(GPU/CPU, 정밀도, 분석 시간) |
| 이미지 카드 | 현재 이미지 폴더 · 저장 폴더, **＋ 파일 추가**, 이미지 목록(✔ = 저장 완료) |
| 원본 카드 | 점을 찍는 곳. 오른쪽 위 **🖌 브러시**, 아래 알약에서 **작물 점 / 배경 점** 모드 선택 |
| 결과 카드 | 분할 결과. 여기서도 점을 똑같이 찍고 수정 가능. 오른쪽 위에서 보기 방식, 아래에서 투명도 |
| 오른쪽 카드 | 객체 목록(**전체 지우기**, ＋ 새 객체), 점 목록, 마스크 후보, 브러시, 표시 설정 |

두 화면(원본·결과)의 확대와 이동은 함께 움직여서 같은 위치를 나란히 비교할 수 있습니다.

> v1(`AI_이미지_세분화_시스템.html`)은 이전 버전(어두운 화면)입니다. 점 찍기 · 저장 기능은 같지만 **브러시 · 전체 지우기 · 새 작업은 없습니다.**

## 4. 라벨링 방법

### 기본 흐름
1. 왼쪽 목록에서 이미지를 고릅니다. (처음 열 때 이미지 분석에 몇 초 걸립니다)
2. 작물 위를 **좌클릭** → 초록 점(작물)이 찍히고 결과가 바로 나옵니다.
3. 마스크가 배경까지 넘쳤으면 넘친 곳을 **우클릭** → 빨간 점(배경)
4. 마스크가 작물을 덜 덮었으면 빠진 곳을 **좌클릭**해서 작물 점을 추가
5. 결과가 마음에 들면 **Ctrl+S** 로 저장하고 **D**(또는 →)로 다음 이미지로 이동

> 다른 이미지로 이동할 때는 기본적으로 자동 저장됩니다. (위쪽 "자동저장" 스위치)

### 점 다루기
| 동작 | 결과 |
|---|---|
| 좌클릭 | 현재 모드의 점 추가 (기본: 작물) |
| 우클릭 | 반대 모드의 점 추가 (기본: 배경) |
| 점 드래그 | 점 위치 이동 (결과가 실시간으로 바뀜) |
| 점 위에서 우클릭 | 점 삭제 |
| 점 더블클릭 | 작물 ↔ 배경 전환 |
| 점 목록의 ⇄ / ✕ | 전환 / 삭제 |

### 여러 포기를 따로 라벨링하기 (객체)
- **N** 을 누르거나 객체 카드의 **＋** 를 누르면 새 객체가 생깁니다. 이후 찍는 점은 새 객체에 들어갑니다.
- 객체마다 색이 다르고, 저장할 때 객체별 번호 마스크(`instances`)가 따로 만들어집니다.
- 객체 이름은 목록에서 클릭해서 바꿀 수 있고, **Tab** 으로 객체를 바꿔 가며 선택합니다.

> 한 객체에 여러 포기를 점으로 다 찍는 것보다 **포기마다 객체를 나누는 것**이 훨씬 정확합니다.

### 마스크 후보란?
점이 1개일 때는 "잎 하나인지, 포기 전체인지, 모든 작물인지" 애매합니다. 그래서 SAM 은 **크기가 다른 마스크 3개**를 점수와 함께 돌려줍니다.

- 점수는 모델이 **스스로 예측한 품질**입니다. 정답 대비 정확도가 아니며, 1을 조금 넘을 수도 있습니다.
- 자동으로 **점과 가장 잘 맞는**(작물 점이 안에, 배경 점이 밖에 있는) 후보 중 점수가 높은 것이 선택됩니다.
- 다른 후보가 맞으면 막대를 누르거나 **[ / ]** 키로 바꾸세요. 직접 고른 후보는 저장 후에도 기억됩니다.
- 브라우저 버전은 점 개수와 상관없이 항상 후보 3개를 보여줍니다. (파이썬 버전은 점이 2개 이상이면 1개)

### 결과 보기 방식 (결과 카드 오른쪽 위, **M** 키)
- **오버레이**: 원본 위에 색 마스크
- **마스크**: 저장될 흑백 마스크와 같은 모양
- **객체별**: 객체마다 다른 색
- **잘라내기**: 배경을 지우고 작물만 표시

### 브러시로 문질러 채우기 · 지우기 (v2 · 서버 버전)
점만으로 잘 안 잡히는 부분(예: 줄기가 겹쳐서 마스크 가운데가 비는 곳)을 **직접 문질러서 채우거나 지울 수 있습니다.**

| 동작 | 방법 |
|---|---|
| 브러시 켜기 / 끄기 | 원본 카드 오른쪽 위 **🖌 브러시**, 오른쪽 카드의 브러시 스위치, 또는 `B` |
| 칠하기 (마스크에 추가) | 브러시를 켜고 **좌클릭 드래그** |
| 지우기 (마스크에서 제거) | **우클릭 드래그**, 또는 **지우기** 선택 후 좌클릭 드래그 (`E` 로 전환) |
| 크기 | 크기 슬라이더, `-` / `=`, 또는 `Alt` + 휠 |
| 이 객체의 브러시만 지우기 | 오른쪽 **이 객체의 브러시 지우기** |
| 되돌리기 | `Ctrl+Z` (획 단위) |

- 브러시는 **선택한 객체**에 적용됩니다. 점을 옮기거나 추가해서 SAM 이 다시 계산해도 **칠한 부분은 그대로 유지**됩니다.
- 칠한 획은 `annotations` JSON 의 `strokes` 에 저장되어, 다시 열면 그대로 복원됩니다. 저장되는 마스크에는 브러시 결과가 반영됩니다.

### 전체 지우기 (v2 · 서버 버전)
객체 영역의 **전체 지우기**는 현재 이미지의 점 · 객체 · 브러시를 모두 지웁니다. `Ctrl+Z` 로 되돌릴 수 있고, **저장하기 전까지 이미 저장된 파일은 바뀌지 않습니다.**

## 6. 폴더와 저장

### 이미지 폴더
- **↺ 새 작업**에서 폴더를 고르거나, 이미지를 화면에 끌어다 놓거나 **＋ 파일 추가**로 목록에 넣을 수 있습니다.
- 브라우저 버전 지원 형식: **jpg, jpeg, png, bmp, webp** (tif 는 브라우저가 열지 못함 → 파이썬 버전 사용)
- 파이썬 버전 지원 형식: jpg, jpeg, png, bmp, tif, tiff, webp

### 저장 폴더
| | 브라우저 버전 | 파이썬 버전 |
|---|---|---|
| 기본 | 처음 저장할 때 직접 선택 (보통 `문서` 안에 새 폴더) | `문서\SAM_Labeler\labels\<이미지폴더 이름>` |
| 기존 결과 이어서 | 이미지 폴더에 `sam_labels` 가 있으면 **기존 sam_labels** 버튼이 나타남 | 이미지 폴더 안에 `sam_labels` 가 있으면 자동으로 사용 |
| 바꾸기 | 위쪽 **↺ 새 작업** → 저장 폴더 **선택** | 위쪽 **↺ 새 작업**, 또는 왼쪽 저장 폴더 **📁 찾아보기** / 경로 입력 |

- 저장 폴더를 바꿔도 **작업 중인 점은 그대로** 남고, 다음 저장 때 새 폴더에 저장됩니다.
- 목록의 ✔ 표시는 **현재 저장 폴더 기준**입니다.
- 폴더 저장을 지원하지 않는 브라우저(Firefox 등)에서는 저장 시 파일이 **다운로드**됩니다.

### ↺ 새 작업 (다른 폴더로 새로 시작)
불러온 이미지를 다 끝내고 **다른 이미지 폴더 · 다른 저장 폴더로 새로 시작**할 때 씁니다. (v2 · 서버 버전)

1. 위쪽 **↺ 새 작업**을 누릅니다. 지금 작업 중인 폴더와 완료 수가 보입니다.
2. **① 이미지 폴더**와 **② 저장 폴더**를 고릅니다.
   - v2: **선택** 버튼으로 폴더 선택 창을 엽니다. 저장 폴더를 **나중에**로 두면 처음 저장할 때 고릅니다.
   - 서버 버전: **📁 찾아보기** 또는 경로 입력. 저장 폴더를 비우면 기본 위치에 저장합니다.
3. **새 작업 시작**을 누르면 새 폴더의 이미지 목록으로 바뀝니다.

- 지금 작업 중인 이미지는 **이전 저장 폴더에 자동 저장**된 뒤 바뀝니다. (자동저장이 꺼져 있으면 확인을 묻습니다)
- 저장 폴더에 쓸 수 없으면 오류를 보여주고 아무것도 바꾸지 않습니다.
- v2 에서 이미지 폴더를 그대로 두고 저장 폴더만 바꾸면, 보던 이미지 위치가 유지됩니다.

### 저장되는 파일
```
<저장 폴더>\
 ├ masks\<이미지이름>.png        흑백 마스크 (작물 255, 배경 0)
 ├ instances\<이미지이름>.png    객체 번호 마스크 (배경 0, 객체 1, 2, 3 …)
 ├ overlays\<이미지이름>.jpg     확인용 (원본 + 색 마스크)
 ├ annotations\<이미지이름>.json 점 좌표, 모델, 점수, 면적, bbox
 └ _source_folder.txt           어느 이미지 폴더의 결과인지 기록
```

- 마스크 크기는 원본 이미지와 같습니다. (사진의 회전 정보(EXIF)가 적용된 방향 기준)
- `instances` 는 객체가 255개 이하면 8비트, 그보다 많으면 16비트 PNG 입니다.

`annotations` JSON 예시:
```json
{
  "image": "IMG_0001.jpg",
  "width": 4000, "height": 3000,
  "weight": "vit_l",
  "saved_at": "2026-09-23 13:05:36",
  "runtime": "browser · webgpu · fp16",
  "point_label": { "1": "작물(전경)", "0": "배경" },
  "objects": [
    {
      "id": 1,
      "name": "작물 1",
      "points": [ { "x": 1036.2, "y": 1404.3, "l": 1 },
                  { "x": 1327.8, "y": 924.1,  "l": 0 } ],
      "mask_index": 1,
      "user_pick": false,
      "score": 0.97,
      "color": "#2f4fe0",
      "area": 696942,
      "bbox_xyxy": [620, 410, 1890, 2530]
    }
  ]
}
```
| 항목 | 뜻 |
|---|---|
| `l` | 1 = 작물 점, 0 = 배경 점 |
| `weight` | 사용한 모델 (`vit_b`, `vit_l`, `vit_h`) |
| `runtime` | 브라우저 버전에만 있음. 실행 장치와 정밀도 |
| `strokes` | 브러시 획 (v2 · 서버 버전). `m`(add=칠하기 / erase=지우기), `r`(반지름 px), `pts`(좌표 목록) |
| `mask_index` / `user_pick` | 선택한 마스크 후보 번호 / 직접 골랐는지 여부 |
| `score` | 선택한 후보의 SAM 예측 점수 |
| `area` | 마스크 픽셀 수 |
| `bbox_xyxy` | 객체를 감싸는 사각형 (x1, y1, x2, y2) |

## 8. 파이썬 서버 버전

`.pth` 가중치를 그대로 쓰고, 인터넷 없이, ViT-H 를 정상 속도로 쓰고 싶을 때 사용합니다.

### 설치 (처음 한 번)
| 항목 | 내용 |
|---|---|
| 파이썬 | Anaconda 또는 Python 3.9 이상 |
| GPU (권장) | NVIDIA GPU + 드라이버 (없으면 CPU 로 매우 느림) |
| GPU 메모리 | ViT-B 약 2GB, ViT-H 약 4~5GB 여유 권장 |

1. **PyTorch** 설치 — GPU 를 쓰려면 [pytorch.org](https://pytorch.org/get-started/locally/) 에서 CUDA 버전에 맞는 명령을 확인하세요. (예: CUDA 12.6)
   ```bash
   pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126
   ```
2. 나머지 패키지 설치
   ```bash
   pip install -r requirements.txt
   ```
3. 가중치(`.pth`)를 `sam_label_server.py` 와 같은 폴더에 둡니다.

| 이름 | 파일명 | 다운로드 |
|---|---|---|
| ViT-B | `sam_vit_b_01ec64.pth` | https://dl.fbaipublicfiles.com/segment_anything/sam_vit_b_01ec64.pth |
| ViT-L | `sam_vit_l_0b3195.pth` | https://dl.fbaipublicfiles.com/segment_anything/sam_vit_l_0b3195.pth |
| ViT-H | `sam_vit_h_4b8939.pth` | https://dl.fbaipublicfiles.com/segment_anything/sam_vit_h_4b8939.pth |

### 실행
1. **`run_sam_label.bat` 을 더블클릭**합니다. 모델을 불러오면 브라우저가 자동으로 열립니다. (안 열리면 `http://127.0.0.1:8765`)
2. **검은 창은 사용하는 동안 닫지 마세요.** 닫으면 서버가 꺼집니다.
3. `sam_label.html` 만 따로 열면 "서버가 실행되고 있지 않습니다" 안내가 뜹니다. 서버를 켜면 자동으로 연결됩니다.

`run_sam_label.bat` 은 파이썬을 `SAM_PYTHON` 환경변수 → 폴더 안 `python\python.exe` → Anaconda/Miniconda → PATH 순서로 찾습니다.

### 브러시 · 전체 지우기 · 새 작업
v2 와 같은 기능입니다. 4장(브러시 · 전체 지우기)과 6장(새 작업)을 보세요. 서버 버전은 새 작업에서 폴더 경로를 직접 입력할 수도 있습니다.

### 실행 옵션 (고급)
```bash
python sam_label_server.py --images D:\data\crops --output D:\data\crops_labels --weight vit_h
```
| 옵션 | 설명 | 기본값 |
|---|---|---|
| `--images` | 이미지 폴더 | 마지막에 쓴 폴더 |
| `--output` | 저장 폴더 | 마지막에 쓴 폴더 / 기본 위치 |
| `--weight` | 시작 가중치 (`vit_b`, `vit_l`, `vit_h`) | `vit_b` |
| `--weights` | 가중치 파일이 있는 폴더 | 프로그램 폴더 |
| `--device` | `cuda` 또는 `cpu` | GPU 가 있으면 `cuda` |
| `--port` | 서버 포트 | `8765` |
| `--open` | 준비되면 브라우저 자동 열기 | 꺼짐 (bat 에서는 켜짐) |
| `--settings` | 설정 파일 경로 | `%APPDATA%\SAM_Labeler\settings.json` |

## 9. 자주 묻는 문제

### 브라우저 버전
**"모델을 불러오지 못했습니다" / "AI 엔진을 불러오지 못했습니다"**
→ 인터넷 연결을 확인하고 **다시 시도**를 누르세요. 회사·학교 네트워크에서 `huggingface.co`, `cdn.jsdelivr.net` 이 막혀 있으면 받을 수 없습니다.

**너무 느려요**
→ 위쪽 상태가 `CPU` 로 나오면 그래픽카드(WebGPU)를 쓰지 못하는 상태입니다. Chrome/Edge 를 최신으로 업데이트하고 그래픽 드라이버를 확인하세요. ViT-H 는 원래 느리니 ViT-L 을 쓰세요.

**새 작업의 폴더 선택 창이 안 떠요, 저장이 안 돼요**
→ Chrome 또는 Edge 에서 여세요. 권한을 묻는 창에서 **허용**을 눌러야 합니다. "저장 폴더에 쓸 권한이 없습니다" 가 나오면 저장 폴더를 다시 선택하세요.

**지난 폴더가 바로 안 열려요**
→ 브라우저 보안상 매번 확인이 필요합니다. 왼쪽 **지난 작업 → 이어서 열기**를 누르세요.

**모델 파일이 용량을 차지해요 / 모델이 이상하게 동작해요**
→ **설정 → 다운로드한 모델 지우기** 후 다시 불러오세요.

**tif 이미지가 목록에 안 보여요**
→ 브라우저가 tif 를 열지 못합니다. jpg/png 로 바꾸거나 파이썬 버전을 쓰세요.

### 파이썬 서버 버전
**"SAM 서버가 실행되고 있지 않습니다" / `Failed to fetch`**
→ `run_sam_label.bat` 을 실행하세요. 화면은 2초마다 자동으로 다시 연결합니다.

**"포트 8765 가 이미 사용 중입니다"**
→ 이미 켜져 있습니다. 열려 있는 검은 창을 쓰거나, 닫고 다시 실행하세요. 다른 프로그램이 쓰고 있다면 `run_sam_label.bat --port 8800`.

**"GPU 메모리 부족"**
→ 다른 GPU 프로그램(학습 코드, 주피터 등)을 끄거나 ViT-B 를 쓰세요.

**"이 폴더에는 저장할 수 없습니다"**
→ 읽기 전용이거나 권한이 없는 폴더입니다. 다른 저장 폴더를 지정하세요.

**"필요한 패키지가 없습니다"**
→ 8장 설치를 진행하세요. 검은 창에 나온 `pip install` 명령을 그대로 실행하면 됩니다.

### 공통
**저장했던 점이 다시 보이나요?**
→ 네. 같은 저장 폴더를 쓰는 한, 저장한 이미지를 다시 열면 점이 복원되고 목록에 ✔ 가 표시됩니다.
